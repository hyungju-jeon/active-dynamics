Adaptive async iCEM planning behavior

A timeline view of how `adaptive_async_realtime` and `adaptive_async_anytime` split the foreground agent loop from the background planner process while executing fine actions from a coarse iCEM plan.

Labels and variables

Agent
Foreground loop: chooses one fine action, steps the environment, updates belief, and launches or refreshes planning.
Planner
Background process running iCEM on a copied model and metric snapshot.
t
Fine environment step. In TBME this is one 10 ms bin.
chunk
Fine-action interval before the agent may swap buffers. Default: 20.
coarse_dt_factor
Fine steps represented by one coarse iCEM action. Default: 20.
H
Coarse iCEM planning horizon. Default: 40 coarse actions.
buffer_index
Index of the next fine action in the execution buffer.
z_boundary
Predicted state after rolling `buffer[buffer_index:chunk]` forward.
theta version
`parameter_update_version`, incremented when the parameter posterior changes.
